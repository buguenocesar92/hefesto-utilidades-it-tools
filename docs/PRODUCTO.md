# Propuesta comercial
Portal técnico como complemento de soporte gestionado, intranet de una agencia o formación. Cobrar instalación, acceso, mantenimiento y personalización contratada; no prometer alto ingreso por herramienta genérica ni vender exclusividad del software libre.

Incluido: interfaz nativa, gateway autenticado, publicación por proxy, procedimientos de recuperación y datos ficticios. No incluye marca blanca modificada, facturación, usuarios individuales, API CRUD ni almacenamiento central.

Fork sharevb/it-tools bajo GPLv3; se conserva atribución y licencia incluida. Caddy se utiliza como componente separado. Al modificar/distribuir código, conservar avisos y cumplir licencias aplicables. No se elimina la identidad de autores.

Mantener whitelist de herramientas aceptadas tras probarlas con CSP. Una herramienta del catálogo que requiera servicios externos puede quedar bloqueada: documentar limitación y no retirar la protección de forma general.
